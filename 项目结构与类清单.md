## 四、每个类的职责一句话

**Controller（薄，只做转发）**
- AuthController：登录/登出，返回 token
- DishController：公开菜品列表/详情
- CustomerOrderController：下单、支付、取消、查我的订单和消费记录
- EmployeeController：查我的窗口、本窗口订单、接单、改状态、查消费记录
- AdminEmployeeController / AdminDishController / AdminWindowController / AdminDiscountController：对应资源的管理（增删改查）
- AdminStatisticsController：营业额/订单数/完成率、菜品销量排行

**Service（业务逻辑，@Transactional）**
- AuthService：校验账号密码、调用 StpUtil.login 签发 token、微信 openid 登录、登出（StpUtil.logout）
- DishService：菜品增删改查 + 上架过滤
- OrderService：下单（算总额/套折扣/扣库存）、支付、取消（回补库存）、接单、改状态、查订单与消费记录
- EmployeeService：员工增删改查、重置密码
- WindowService：窗口增删改查、按员工查窗口
- DiscountRuleService：折扣规则增删改查
- StatisticsService：营业额/订单数/完成率统计、销量排行

**Mapper（只有 SQL）**
- CustomerMapper / EmployeeMapper / PickupWindowMapper / DishMapper / DiscountRuleMapper / OrderMapper / OrderItemMapper：均继承 `BaseMapper<实体>`，单表增删改查自动生成；只写多表联查、条件更新等自定义 SQL（如扣库存、统计）

## 五、建议开发顺序（从简到繁）

1. 建库建表（执行 ddl.sql）
2. 搭骨架：启动类 + Result + 异常处理 + entity（7 个实体）
3. 做「菜品浏览」：DishController → DishService → DishMapper（最简单，无鉴权）
4. 做「认证」：AuthController + Sa-Token（StpUtil.login 登录 + SaInterceptor 路由拦截 + @SaCheckRole 鉴权）
5. 做「顾客下单」：OrderService.create（核心，含事务、折扣、库存）
6. 做「员工」接口
7. 做「管理员」接口（大多是简单 CRUD）
8. 最后做「统计」

## 六、两个可选调整

- **用 JPA 替代 MyBatis-Plus**：把 `mapper/` 换成 `repository/`，类名如 `DishRepository extends JpaRepository<Dish, Long>`，增删改查自动生成，只需写少量 @Query。
- **合并 Controller**：若嫌 9 个太多，可把 5 个 Admin 控制器合并成 1 个 `AdminController`（路径不变），或把订单相关合并成一个 `OrderController`。

## 七、Sa-Token 鉴权要点

- **依赖**：`cn.dev33:sa-token-spring-boot4-starter:1.46.0`
- **登录**：`StpUtil.login(id)` 签发 token，`StpUtil.getTokenValue()` 返回给前端
- **当前用户**：`StpUtil.getLoginId()` 获取登录人
- **注解鉴权**：`@SaCheckLogin`（需登录）、`@SaCheckRole("admin")`（管理员专属）
- **路由拦截**：`SaTokenConfigure` 里用 `SaInterceptor` + `SaRouter`，放行 `/api/auth/**` 和 `/api/dishes/**`，其余 `checkLogin`，`/api/admin/**` 额外 `checkRole("admin")`
- **两套账号防撞号**：顾客（customer_id）与员工（employee_id）各自自增会撞号，登录时给 ID 加前缀（如 `employee:5` / `customer:5`），或用 Sa-Token 多账号模式（`StpUtil` 管员工、`StpUserUtil` 管顾客）
- **token 存储**：默认内存，单机够用；后续要分布式再配 Redis
